### F6. 新根因假设 — Fisher-proxy block loss 与 v5 input-space metric 不对齐（H2）

外层 block search 的 loss（`block_search.py:_hessian_block_error`）：
$$
L_{block} = \mathbb{E}[H \cdot (Y_{orig} - Y_{hat})^2], \quad H = Y_{orig}^2
$$
是 **输出空间** Fisher-proxy weighted MSE。

v5 metric（plan §2）推导自 **输入空间** 重构：
$$
\mathcal{L}_{v5} = \mathbb{E}_{m}\|W X_m - \hat W X_m\|_F^2,\quad \mathcal{I}(i,j) = \frac{W_{ij}^2}{[H_{in}^{-1}]_{jj}}
$$

两个目标函数朝不同方向优化 → search 选出的非均匀 `{s_l}` 不是 v5 mask 下的最优预算。

- v1/v4 metric 本质也在输出空间近似（WANDA/sensitivity 尺度是 `|W|·||X||`，和 `||Y||` 同阶）→ 与外层 Fisher 一致 → search 正收益。
- v5 输入空间 OBS → 和 Fisher proxy 在不同流形上 → search 反而引入次优配置。

**落地方向**（两条路）：
1. **改外层 loss**：把 `H = Y_orig²` 改为基于块输入 Hessian 的 weighting，让外层/内层都在输入空间。`_hessian_block_error` 需改造。
2. **限制 candidate search space**：既然非均匀配置对 v5 有害，生成器只保留"轻扰动 uniform"候选（±0.03），让 search 退化为近似 uniform 的微调。**成本最低**的验证方法。

建议先试方案 2（`_generate_candidates` 里加 v5 分支，只保留 uniform + 4 个 ±0.03 扰动）。

### F8. 根因更正 — OBS 加和跨层不可比（F6 假设被反驳）

F6 假设"外层=Fisher、内层=input OBS 的不一致"是 v5+search 失败的原因。D 组结果证明：**把外层改成与内层完全一致的 OBS input-space 和，效果比 Fisher proxy 更差**。

真正的问题：
1. OBS 的 Σ_i I(i, j_pruned) 是**单层局部 reconstruction error** 的一阶近似，它对"该层被剪掉多少"敏感。
2. 跨层 water-fill 会把预算推给"每个元素 I 值都小"的层（gate_proj、down_proj 等），把这些层压到 s_max=0.9。
3. 但 block 输出误差不是 Σ_l E_l —— 层间有 residual + LayerNorm 的**非线性耦合**，当任一层 s_l→0.9 时该层输出崩溃，整个 block 崩盘。
4. 即 OBS additive assumption（§2）在 s_l ≲ 0.5 时成立，在 s_l → 0.9 时完全失效 → water-fill 的 extrapolation 不合法。

**Fisher proxy（B 组）反而隐式地起到正则作用**：因为它在输出空间衡量误差，会惩罚任何单层的极端分配，只接受"靠近 uniform 的候选"。

### F9. 结论 — v5 Innovation 2 应重新定位

| 机制 | v5 per-element mask | 跨层 budget 分配 |
|---|---|---|
| v5 direct (A) | mixture-H OBS ✓ | uniform ✓ |
| v5 + Fisher search (B_fix) | mixture-H OBS ✓ | 细扰动（±0.03–0.05 around uniform）✓ |
| v5 + analytic water-fill (D) | mixture-H OBS ✓ | full-range water-fill ✗ |

**Innovation 2 的正确形式**：mixture-H OBS 为**元素级**重要性（不改）；跨层 budget 不做 water-fill，保持 uniform 或用 Fisher proxy 做轻扰动搜索。

**论文叙事调整**：
- §3/§4：v5 mixture-H metric 是唯一 innovation（Innovation 1 实为 metric，Innovation 2 是 mixture 形式本身，不是 search）。
- §5/§6：search 章节降权，只做 B 组"小扰动 + Fisher proxy"，而非 analytic/input-space。
- §13.6 "两层 Hessian 乘法增益"**被实验否定**，需从 writing 中移除。
